AssignTaxonomy.jl

Taxonomic classification of DNA sequences with the RDP naive Bayesian classifier (Wang et al. 2007), as in R's dada2::assignTaxonomy, and exact-match species assignment, as in dada2::assignSpecies and dada2::addSpecies. Results match R's.

using Pkg
Pkg.add("AssignTaxonomy")

Usage

seqs is a vector of sequences, a FASTA file, or a sequence table from DenoiseDNA.jl. References are the dada2-formatted training files (see the DADA2 reference databases).

using AssignTaxonomy

taxa = assignTaxonomy(seqs, "silva_nr99_v138.2_toGenus_trainset.fa.gz")
taxa = addSpecies(taxa, "silva_v138.2_assignSpecies.fa.gz")

The result is a TaxonomyTable, a Tables.jl table with a Sequence column and one column per rank (missing where the bootstrap support is below minBoot=50):

using DataFrames
DataFrame(taxa)

Train once and reuse the model on several sets of sequences:

model = train_taxonomy("silva_nr99_v138.2_toGenus_trainset.fa.gz")
taxa1 = assignTaxonomy(seqs1, model)
taxa2 = assignTaxonomy(seqs2, model)

seed makes the bootstrap reproducible: assignTaxonomy(seqs, ref; seed=1) gives R's results after set.seed(1), except for sequences whose best genera tie exactly, which R breaks at random.

assignSpecies(seqs, ref) gives the genus and species of each sequence by exact matching alone.

The older assign_taxonomy(seq_fasta, ref_fasta), returning a ClassificationResult, is still available.

A trained classifier: for each "genus" (unique full lineage string in the reference) the log-probability of observing each k-mer. Made by train_taxonomy; can be passed to assignTaxonomy in place of the reference file.

AssignTaxonomy.TaxonomyTable — Type
TaxonomyTable

Result of assignTaxonomy and addSpecies: tax[i, l] is the assignment of sequences[i] at rank levels[l] (missing when below the bootstrap threshold or unspecified), and boot[i, l] the bootstrap support out of 100 (only with outputBootstraps=true, otherwise it has no columns). It is a Tables.jl table with columns Sequence and one per rank.

AssignTaxonomy.assignSpecies — Method
assignSpecies(seqs, refFasta; allowMultiple=false, tryRC=false, verbose=false,
              multithread=true) -> TaxonomyTable

Genus and species of each sequence by exact matching against a dada2 species-assignment reference (FASTA ids ID Genus species), as R's dada2::assignSpecies. A sequence gets a genus (species) only if all the references containing it agree on one; with allowMultiple, up to that many species (all if true) are returned, joined with "/". Escherichia and Shigella are reported together as "Escherichia/Shigella". Query sequences must be ACGT only.

source
AssignTaxonomy.assignTaxonomy — Method
assignTaxonomy(seqs, ref; minBoot=50, tryRC=false, outputBootstraps=false,
               taxLevels=["Kingdom",...,"Species"], seed=nothing, multithread=true,
               progress) -> TaxonomyTable

Classify sequences with the RDP naive Bayesian classifier, as R's dada2::assignTaxonomy. seqs is a vector of sequences, a FASTA file, or a sequence table; ref is a dada2-formatted reference FASTA (UNITE files are recognised) or a TaxonomyModel from train_taxonomy. Ranks with bootstrap support below minBoot (out of 100) are missing. With tryRC, the reverse complement is used when it matches better.

Passing seed makes the bootstrap reproducible and identical to R's after set.seed(seed), except where genera tie exactly: R breaks such ties with a non-reproducible random draw.

AssignTaxonomy.assign_taxonomy — Method
assign_taxonomy(seq_fasta, ref_fasta; k=8, n_bootstrap=100, keep_lp=false, lp=false, progress)

Use the RDP Naive Bayesian Classifier algorithm to assign taxonomic classifications based on DNA sequence data, exactly as R's dada2::assignTaxonomy does. This function takes (the paths to) two fasta files seq_fasta and ref_fasta, containing target sequences and a reference database respectively. It returns a Tables.jl compatible ClassificationResult, containing the target sequence IDs, target sequences, taxonomic classifications (Kingdom to Genus, without a bootstrap cut-off) and the bootstrap confidence of the genus.

  • seq_fasta: Path to a fasta of sequences to be classified. A vector of sequences (and optionally ids) can be given instead.

  • ref_fasta: Path to a fasta reference database. A vector of reference sequences and a matrix of their taxonomies (as from get_reference) can be given instead.

  • k: Length of kmers to use.

  • n_bootstrap: Number of bootstrap iterations to perform.

  • keep_lp: Also return the trained model (a TaxonomyModel) if true.

  • lp: A trained model to use instead of training on the reference again.

  • progress: Show progress bars for training and classification. Defaults to on in interactive sessions and terminals; set it for every call with AssignTaxonomy.setprogress!.

ref_fasta must be a DADA2-formatted reference database. See here for examples. For R's interface (minBoot, tryRC, ...) use assignTaxonomy.
